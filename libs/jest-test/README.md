# @interrogate/jest-test

[![License: MIT][license-badge]][license-url]

This is a minimal jest set up using Typescript, ts-jest and the recommended vite-react
tsconfig.json. Having run into situations where legacy projects have a bunch of jest tests and
aren't ready to move everything to vite at once, I thought it'd be useful for me to have a pared
down version of this for reference.
